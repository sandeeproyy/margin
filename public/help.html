From anywhere
to your desk.

Margin lives on the laptop. To print from outside your home Wi-Fi, you need a safe way back to that laptop. Two routes work beautifully: a Cloudflare Tunnel, or a private Tailscale network.

CostFree to start
The lockPIN + HTTPS

01

First, the same Wi-Fi.

Before reaching for a tunnel, make sure the simple path works. Start Margin on the laptop, then open the address it prints in the terminal from your phone. They need to be on the same network.

On the laptop npm start

The terminal shows a local address, a mobile address, and a QR code. Scan the code, or type the mobile address into your phone. The first time, Windows may ask whether Node.js can talk on the network — allow private networks, not public ones.

↳

Same Wi-Fi only. The QR code stops working as soon as your phone leaves the house, or the laptop changes networks.

02

The simplest way out: Cloudflare Tunnel.

A Cloudflare quick tunnel gives the laptop a temporary HTTPS address on the public internet. Your router stays untouched, and your phone can print from a train, an office, or a different country. Cloudflare connects outbound to the laptop; nothing is opened in your firewall.

  1. 1
    Install cloudflared on the laptop.

    Open PowerShell and run the command below. If you already have it, skip ahead.

One-time install winget install --id Cloudflare.cloudflared
  1. 2
    Start the print room.

    Leave this terminal window open. This is the part holding the printer.

Terminal one npm start
  1. 3
    Open the tunnel in a second terminal.

    The included share script starts cloudflared for you and checks that the room is awake first.

Terminal two npm run share

Look for a line like https://quiet-paper-1234.trycloudflare.com. Open that exact address on your phone, enter the PIN, and print. Keep both terminal windows open while you need the room.

!

Quick tunnels are temporary. The address changes when cloudflared restarts. For a permanent address, create a named Cloudflare Tunnel with your own domain in the Cloudflare dashboard. The commands are the same; the URL just stops changing.

↳

Treat the link like a key. Send the URL and the PIN separately, and only to people you would let into the room. This is a one-user print room, not a multi-user service.

03

The private way: Tailscale.

If you only need to reach the printer from your own devices, Tailscale is the quieter option. It builds an encrypted private network between the laptop and your phone. No public URL exists, and nothing is exposed to the open internet.

  1. 1
    Install Tailscale on the laptop and the phone.

    Sign in to the same account on both. The Tailscale app shows the laptop’s private address and name.

  2. 2
    Start Margin on the laptop.

    Then, on the phone, open the laptop’s Tailscale address with :3000 on the end.

On the phone http://your-laptop-name:3000

If the phone cannot connect, make sure Tailscale is switched on for both devices, and that Node.js is allowed through Windows Firewall on private networks. Tailscale’s own encryption protects the trip; the PIN still guards the room itself.

↳

Cloudflare or Tailscale? Cloudflare is easier to send to a family member. Tailscale is tidier when the only person printing is you.

04

Keep the room open.

The laptop is doing the work. It has to be awake, online, and running Margin when a document arrives. Plug it in, and check its sleep settings: if the lid closes and Windows sleeps, the print room goes dark with it.

PrinterOn, loaded, USB connected
LaptopAwake and on the network
MarginRunning in a terminal
TunnelLeft open if printing remotely

To start Margin automatically when you sign in to Windows, put a shortcut to a small start-margin.cmd file in your Startup folder. The README has the exact steps. Until then, npm start is the whole ritual.

↳

Files do not linger. Uploaded documents are removed after about two hours. The history keeps only the file name, settings, and result. The Windows print queue is separate, so clear it if an old job jams the line.

05

When something sticks.

Nothing comes out, but the app says “sent”.

The app confirms that Windows accepted the job, not that ink met paper. Open Settings → Bluetooth & devices → Printers & scanners → EPSON L3110 Series → Open print queue. If a job is paused or stuck, cancel it and try a one-page test. Check paper, ink levels, and that the printer is not offline.

A Word, Excel, or PowerPoint file will not convert.

Office conversion uses the desktop Microsoft Office already installed on the laptop. Microsoft 365 in a browser is not enough. If conversion keeps failing, open the file in Office, choose File → Save As → PDF, and upload the PDF instead.

The phone says the connection is not private.

Use the full https:// address printed by cloudflared, not the laptop’s local IP. If you are on the same Wi-Fi, the plain http:// address is expected and fine; browsers only warn on public addresses without a certificate.

What is the print authorization PIN?

The print PIN is a shared code (default 292929) provided by the print room owner. It ensures that only authorized people can send physical jobs to paper. Once entered, your session stays authorized for 30 minutes.

Can the administrator view my documents?

No. Margin is built with privacy-first isolation. Each member has their own independent history and quota. Even the print room administrator cannot view, download, or access other users' documents.

The quick tunnel address changed again.

That is how quick tunnels work. Either restart npm run share and share the new address, or set up a named Cloudflare Tunnel with a domain so the address stays the same.

The print queue is jammed.

Cancel the stuck job in the Windows queue. If the queue refuses to clear, restart the Print Spooler service from Services, or run Restart-Service Spooler in an administrator PowerShell window. Then print a single test page.
